# 🖨️ Remote Printer: הדפסה מרחוק

תוכנה קטנה שרצה כל הזמן על מחשב שמחובר למדפסת.
שולחים אליה קובץ **PDF או Word** מכל מקום (מהטלפון או ממחשב אחר) והיא **מדפיסה מיד**,
בלי חלון אישור ובלי שמישהו צריך ללחוץ על משהו במחשב.

שתי דרכים לשלוח קובץ (אפשר להפעיל אחת מהן או את שתיהן):

| דרך | איך שולחים | הערות |
|---|---|---|
| **בוט טלגרם** (מומלץ) | שולחים את הקובץ לבוט בטלגרם | מקבלים תשובה "✅ נשלח למדפסת". רק משתמשים מורשים יכולים להדפיס. |
| **מייל** | שולחים מייל עם קובץ מצורף | רק מכתובות מורשות, ועם מילת סוד בנושא. |

התוכנה רק **יוצאת** לאינטרנט (בודקת אם הגיע משהו), ולכן אין צורך לפתוח פורטים בראוטר או להגדיר IP קבוע.

---

## התקנה ב-Windows (פעם אחת)

### 1. Python
מורידים מ-[python.org](https://www.python.org/downloads/) ומתקינים.
**חשוב:** במסך הראשון של ההתקנה מסמנים ✅ `Add python.exe to PATH`.

אחר כך פותחים חלון **cmd** בתיקייה של התוכנה ומריצים:
```
pip install -r requirements.txt
```
(זה מתקין את `pywin32`, שדרכו התוכנה מפעילה את Word ברקע.)

### 2. הדפסת PDF בשקט: SumatraPDF
ל-Windows אין דרך מובנית להדפיס PDF בלי לפתוח חלון. מורידים את
[SumatraPDF](https://www.sumatrapdfreader.org/download-free-pdf-viewer) (חינמי וקטן),
עדיף את הגרסה ה-**Portable** (קובץ exe אחד), **ושמים את קובץ ה-exe באותה תיקייה של התוכנה**.
התוכנה תמצא אותו לבד.

### 3. הדפסת Word
- אם מותקן **Microsoft Word**, הוא ישמש להדפסה (ברקע, בלי חלון, ומאקרו לא ירוץ אף פעם).
  **פתחו את Word פעם אחת ידנית** וסגרו את כל חלונות הפתיחה (הפעלה, פרטיות וכו'), כדי שלא יחסמו את ההדפסה האוטומטית.
- אם אין Word, מתקינים [LibreOffice](https://www.libreoffice.org/) (חינמי), והתוכנה תשתמש בו.

### 4. יצירת בוט טלגרם
1. בטלגרם מחפשים את **@BotFather** ושולחים לו `/newbot`.
2. בוחרים שם ושם משתמש לבוט (למשל `my_home_printer_bot`).
3. מקבלים **טוקן**, מחרוזת כמו `123456789:AAH...`. שומרים אותו בסוד.

### 5. קובץ ההגדרות
מעתיקים את `config.example.ini` לקובץ חדש בשם `config.ini`, פותחים אותו ב-Notepad ומדביקים את הטוקן:
```ini
[telegram]
enabled = yes
bot_token = 123456789:AAH...
allowed_user_ids =
```

### 6. הרשאה לטלפון שלכם
1. מריצים `run.bat` (נפתח חלון שחור, וזה תקין).
2. בטלגרם פותחים את הבוט ושולחים `/start`.
3. הבוט יענה: *"אין לך הרשאה... מספר המשתמש שלך: 123456789"*.
4. מעתיקים את המספר ל-`allowed_user_ids` ב-`config.ini` (כמה אנשים: מפרידים בפסיק).
5. סוגרים את החלון השחור ומריצים `run.bat` שוב.
6. שולחים לבוט קובץ PDF, והוא אמור לצאת מהמדפסת. 🎉

### 7. הפעלה אוטומטית עם הדלקת המחשב
מריצים פעם אחת את **`install_autostart.bat`**.
מעכשיו התוכנה תעלה לבד ברקע (בלי חלון) בכל פעם שהמשתמש נכנס ל-Windows.
לביטול: `python remote_printer.py --remove-autostart`.

### 8. הגדרות Windows חשובות
- **שינה:** הגדרות > מערכת > צריכת חשמל, ולהגדיר "מצב שינה" ל-**אף פעם**. מחשב ישן לא מדפיס.
- **כניסה אוטומטית:** התוכנה רצה כשהמשתמש מחובר. אם המחשב מופעל מחדש (למשל אחרי עדכון),
  מומלץ להגדיר כניסה אוטומטית למשתמש, או לוודא שמישהו מתחבר.
- **מדפסת ברירת מחדל:** מוודאים שהמדפסת הנכונה היא ברירת המחדל, או כותבים את השם שלה ב-`printer_name`.

## שליחה במייל (אופציונלי)
1. מומלץ ליצור תיבת Gmail **נפרדת** למדפסת.
2. ב-Gmail מפעילים אימות דו-שלבי ויוצרים **סיסמת אפליקציה**:
   חשבון Google > אבטחה > סיסמאות אפליקציה.
3. ב-`config.ini`:
```ini
[email]
enabled = yes
username = my.printer@gmail.com
password = abcd efgh ijkl mnop
allowed_senders = me@gmail.com, office@company.co.il
subject_secret = הדפס7731
```
4. שולחים מייל לכתובת הזו עם קובץ מצורף ועם מילת הסוד בנושא (למשל: `הדפס7731 חשבונית`).

התוכנה בודקת רק מיילים **שלא נקראו**, מהשולחים המורשים ומ-3 הימים האחרונים. מיילים אחרים לא נוגעים בהם.

## בדיקות ותקלות
- **בדיקת מדפסת בלי אינטרנט:** `python remote_printer.py --test-print "C:\path\file.pdf"`
- **מצב ניסיון בלי נייר:** `dry_run = yes` ב-`config.ini`
- **יומן:** הכול נכתב לקובץ `remote_printer.log` בתיקיית התוכנה. זה המקום הראשון לחפש בו כשמשהו לא עובד.
- **בטלגרם:** הפקודה `/status` מחזירה את מצב המדפסת ואת מספר הקבצים בתור.
- הקבצים שהתקבלו נשמרים בתיקייה `received` (אפשר לכבות עם `keep_files = no`).
- שני עותקים של התוכנה לא ירוצו במקביל. השני ייסגר לבד.

## אבטחה
- רק משתמשי טלגרם שהמספר שלהם מופיע ב-`allowed_user_ids` יכולים להדפיס. מספר משתמש בטלגרם אי אפשר לזייף.
- את כתובת השולח במייל **אפשר לזייף**, ולכן כדאי מאוד להגדיר `subject_secret`.
- רק הקבצים `pdf, doc, docx, rtf, odt` מתקבלים. מאקרו בקבצי Word חסום.
- **אל תעלו את `config.ini` לשום מקום** (יש בו הטוקן והסיסמה). הוא כבר מוחרג מ-git.

## Linux / Mac
עובד גם שם: PDF מודפס עם `lp` (CUPS), ו-Word מומר ל-PDF עם LibreOffice ואז מודפס.
להפעלה קבועה ב-Linux אפשר להשתמש ב-systemd:
```ini
# /etc/systemd/system/remote-printer.service
[Unit]
Description=Remote Printer
After=network-online.target

[Service]
User=YOUR_USER
ExecStart=/usr/bin/python3 /path/to/remote_printer.py
Restart=always

[Install]
WantedBy=multi-user.target
```
ואז: `sudo systemctl enable --now remote-printer`
