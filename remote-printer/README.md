# 🖨️ הדפסה מרחוק

נכנסים לאתר מכל טלפון או מחשב, כותבים שם או בוחרים קובץ, ושולחים.
המחשב שמחובר למדפסת מדפיס **מיד**, בלי חלונות ובלי שמישהו ילחץ על משהו.

- **אתר ההדפסה:** https://motiml77.github.io/NAO-back-pack-face-recognitaion/
- **תוכנת ההתקנה למחשב של המדפסת:** [RemotePrinter-Setup.exe](https://github.com/motiml77/NAO-back-pack-face-recognitaion/releases/latest/download/RemotePrinter-Setup.exe)

## הדף נשלח כ-PDF, ולמה זה בטוח להדפסה
האתר מכין דף PDF אחד בגודל A4 לרוחב, ובתוכו כל הדף כתמונה ברזולוציה של 300dpi.
בתוך ה-PDF אין גופנים ואין עימוד שיכולים להשתנות, ולכן הוא יוצא אותו דבר בכל מדפסת.
המחשב מדפיס אותו בשקט עם SumatraPDF, ומתאים אותו לגודל הנייר.
כל קובץ נחתם עם טביעת אצבע (SHA-256), והמחשב בודק שהוא הגיע שלם לפני ההדפסה.

## מה אפשר לשלוח
| | |
|---|---|
| ✍️ **הדפסת שם** | בוחרים נוסח (**לעילוי נשמת / לרפואה שלמה / להצלחה ופרנסה**), כותבים שם (או כמה שמות, שם בכל שורה), ורואים למטה תצוגה מקדימה בדיוק כמו שיודפס: מסגרת מעוטרת, לרוחב, בגופן סת"ם. |
| 📄 **שליחת קובץ** | קובץ PDF או Word (עד 15MB). |

אחרי השליחה מופיע אישור גדול: ⏳ נשלח, 🖨️ המחשב קיבל ומדפיס, ✅ הודפס.
"הודפס" מופיע רק אחרי שהמחשב עקב אחרי ההדפסה בתור של Windows עד שהמדפסת סיימה.
**אם ההדפסה נכשלה,** האתר מציג מה המחשב דיווח (למשל "נגמר הנייר" או "המדפסת לא מחוברת")
ו**צילום מסך מהמחשב של המדפסת** מרגע התקלה. אפשר גם לבקש צילום מסך בכל רגע בכפתור "📷".


## התקנה במחשב של המדפסת (פעם אחת)
מורידים את **RemotePrinter-Setup.exe** ולוחצים עליו פעמיים. זהו.

- **אין שאלות, אין סיסמה ואין בקשת הרשאות מנהל.** ההתקנה רצה ונסגרת לבד.
- הכול בתוך הקובץ: התוכנה, Python וכל הרכיבים, ו-SumatraPDF להדפסת PDF בשקט.
- התוכנה **מתחילה לעבוד מיד**, בלי הפעלה מחדש, ועולה לבד ברקע בכל כניסה ל-Windows.
- **משימת שמירה (watchdog):** כל 5 דקות Windows בודק שהתוכנה פועלת, ומפעיל אותה מחדש אם נסגרה.
- המחשב מוגדר לא להיכנס למצב שינה כשהוא מחובר לחשמל.
- **המדפסת מזוהה אוטומטית:** קודם מדפסת **Pantum**, ואם אין, מדפסת ברירת המחדל האמיתית.
  אם רוצים מדפסת אחרת, בוחרים אותה באתר.

אם Windows מציג "Windows הגן על המחשב", לוחצים **מידע נוסף**, ואז **הפעל בכל זאת**
(הקובץ לא חתום בחתימה דיגיטלית בתשלום).
**קבצי Word** מודפסים רק אם במחשב מותקן Microsoft Word. הדפסת שמות וקבצי PDF עובדות תמיד.
להסרה: הגדרות Windows > אפליקציות > "הדפסה מרחוק".

## הסיסמה של האתר
הסיסמה **לא קשורה להתקנה**. היא נקבעת באתר בלבד, ובדף הכניסה אפשר לסמן "לזכור אותי".
כדי להחליף אותה, מריצים `python remote-printer/tools/set_password.py "הסיסמה החדשה"` ומעלים את האתר.
המחשב של המדפסת קולט את השינוי לבד תוך כמה דקות, בלי להתקין מחדש.

## איך זה עובד, ולמה זה בטוח
- האתר הוא דף סטטי ב-GitHub Pages. ההודעות עוברות דרך [ntfy.sh](https://ntfy.sh), שירות חינמי בלי חשבון, בערוץ קבוע שמובנה בתוכנה.
- הכול מוצפן (AES-256), ו**כל פקודה מהאתר חתומה דיגיטלית** (Ed25519) במפתח שנגזר מהסיסמה.
  המחשב מכיר רק את המפתח *הציבורי* (מתוך `channel.json` באתר): הוא יכול לבדוק חתימה, אבל אי אפשר לייצר חתימה בלי הסיסמה.
  כל הודעה שלא נחתמה בסיסמה הנכונה פשוט נזרקת.
- הסיסמה עצמה לא נשמרת בשום מקום. כש"זוכרים" אותה, המכשיר שומר רק מפתח שנגזר ממנה.
- המחשב רק **יוצא** לאינטרנט, ולכן אין צורך לפתוח פורטים בראוטר.
- אם המחשב כבוי בזמן השליחה, ההדפסה תצא כשהוא יידלק, בתנאי שזה קרה תוך כמה שעות.
- כדאי לבחור סיסמה של 10 תווים לפחות, לא מילה פשוטה.

## מגבלה של שירות ההעברה
ntfy.sh החינמי מאפשר כ-250 הודעות ביום לכל כתובת אינטרנט. בשימוש רגיל (עשרות הדפסות ביום) זה מספיק בהרבה.
האתר בודק את המדפסת כשפותחים אותו, כשלוחצים על הכפתור הירוק, ופעם ב-10 דקות, כדי לא לבזבז הודעות.

## תקלות
- **"המחשב לא עונה"**: בדקו שהמחשב דלוק ומחובר לאינטרנט. משימת השמירה תפעיל את התוכנה מחדש תוך 5 דקות אם היא נסגרה.
- **יומן:** `%LOCALAPPDATA%\RemotePrinter\remote_printer.log`
- **הקבצים שהתקבלו** נשמרים זמנית בתיקייה `received` שם.
