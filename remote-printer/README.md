# 🖨️ הדפסה מרחוק

נכנסים לאתר מכל טלפון או מחשב, כותבים שם או בוחרים קובץ, ושולחים.
המחשב שמחובר למדפסת מדפיס **מיד**, בלי חלונות ובלי שמישהו ילחץ על משהו.

- **אתר ההדפסה:** https://motiml77.github.io/NAO-back-pack-face-recognitaion/
- **תוכנת ההתקנה למחשב של המדפסת:** [RemotePrinter-Setup.exe](https://github.com/motiml77/NAO-back-pack-face-recognitaion/releases/latest/download/RemotePrinter-Setup.exe)

## מה אפשר לשלוח
| | |
|---|---|
| ✍️ **הדפסת שם** | בוחרים נוסח (**לעילוי נשמת / לרפואה שלמה / להצלחה ופרנסה**), כותבים שם (או כמה שמות, שם בכל שורה), ורואים למטה תצוגה מקדימה בדיוק כמו שיודפס: מסגרת מעוטרת, לרוחב, בגופן סת"ם. |
| 📄 **שליחת קובץ** | קובץ PDF או Word (עד 15MB). |

אחרי השליחה הרשימה "נשלחו לאחרונה" מתעדכנת: ⏳ נשלח, 🖨️ מדפיס, ✅ הודפס.
למעלה רואים אם המחשב של המדפסת מחובר, ולמטה אפשר לבחור לאיזו מדפסת להדפיס.

## התקנה במחשב של המדפסת (פעם אחת)
1. מורידים את **RemotePrinter-Setup.exe** ומפעילים אותו.
   אם Windows מציג "Windows הגן על המחשב", לוחצים **מידע נוסף**, ואז **הפעל בכל זאת**
   (התוכנה לא חתומה דיגיטלית בתשלום, וזו ההודעה הרגילה במקרה כזה).
2. בוחרים **סיסמה** (8 תווים לפחות). עם הסיסמה הזאת נכנסים לאתר.
3. זהו. התוכנה פועלת ברקע ועולה לבד בכל הפעלה של המחשב.

הכול נמצא בתוך קובץ ההתקנה (התוכנה, Python וכל הרכיבים, ו-SumatraPDF להדפסה שקטה), ולא צריך להוריד שום דבר נוסף.
לא צריך הרשאות מנהל. ההתקנה גם מגדירה שהמחשב לא ייכנס למצב שינה כשהוא מחובר לחשמל (אפשר לבטל את הסימון).
**קבצי Word** מודפסים רק אם במחשב מותקן Microsoft Word. הדפסת שמות וקבצי PDF עובדות תמיד.

כדי **להחליף סיסמה**, מפעילים שוב את קובץ ההתקנה. להסרה: הגדרות Windows > אפליקציות > "הדפסה מרחוק".

## איך זה עובד, ולמה זה בטוח
- האתר הוא דף סטטי (GitHub Pages) בלי שרת ובלי מסד נתונים.
- ההודעות עוברות דרך [ntfy.sh](https://ntfy.sh), שירות העברת הודעות חינמי שלא דורש חשבון.
- **כל מה שנשלח מוצפן מקצה לקצה** (AES-256) במפתח שנגזר מהסיסמה, וגם שם הערוץ נגזר ממנה.
  בלי הסיסמה אי אפשר למצוא את הערוץ, לקרוא אותו או לשלוח הדפסה. המחשב מתעלם מכל דבר שלא הוצפן במפתח הנכון.
- הסיסמה עצמה לא נשמרת בשום מקום: לא באתר ולא במחשב (רק המפתח שנגזר ממנה).
- המחשב רק **יוצא** לאינטרנט, ולכן אין צורך לפתוח פורטים בראוטר.
- אם המחשב כבוי בזמן השליחה, ההדפסה תצא כשהוא יידלק, בתנאי שזה קרה תוך כמה שעות.

## תקלות
- **"המחשב לא עונה"**: בדקו שהמחשב דלוק ומחובר לאינטרנט ושהסיסמה נכונה. סיסמה שגויה מתנהגת כמו מחשב כבוי, כי היא מובילה לערוץ אחר.
- **יומן:** `%LOCALAPPDATA%\RemotePrinter\remote_printer.log`
- **הקבצים שהתקבלו** נשמרים זמנית בתיקייה `received` שם.
